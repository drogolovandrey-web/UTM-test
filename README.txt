Статический макет интерфейса УТМ (ЕГАИС)
========================================

Это готовый HTML-макет. Работает без сервера, без Python и без интернета:
достаточно открыть index.html двойным щелчком.

Страницы
--------
index.html                                  — главная (основные параметры УТМ)
documents-in.html                           — Входящие документы
documents-out.html                          — Исходящие документы
settings.html                               — Настройки (шестерёнка)
services-product-info.html                  — Проверка продукции
services-rsa.html                           — Генерация ключа доступа к ЕГАИС
services-add-organisation.html              — Добавление организации
services-notification-beginning-turnover.html — Уведомление о начале оборота АП
services-ssp-add.html                       — Добавление ССП
services-barcodes-issuance.html             — Выдача ФСМ
services-balance-transfer.html              — Перенос остатков
services-resend-waybill.html                — Повторная отправка ТТН и Акта
services-declaration-submit.html            — Подать декларацию
services-license.html                       — Лицензирование
services-proactive.html                     — Сообщения и уведомления
services-plomb.html                         — Пломбирование
services-compliance.html                    — Декларации соответствия
services-brewers-registry.html              — Реестр пивоваров
services-digital-excise.html                — Налоговая база
egais-correction.html                       — Корректировочный документ
egais-info.html                             — Запрос сведений ЕГАИС
tech-support.html                           — Техподдержка

Что внутри
----------
- Шапка: «ООО «Пример», ИНН 0000000000, КПП 000000000» — номинальные данные.
- Главная: блок «Основные параметры УТМ» с фиксированными значениями
  (версия, контур, БД, лицензия, чеки, периоды сертификатов).
- Документы: демонстрационные записи, статичные таблицы.
- Настройки: фильтр IP-адресов (тестовые диапазоны), XML-схемы,
  сертификаты (все значения «***»), диагностика (отключена).
- XML-схемы лежат в папке xsd (150 файлов); в таблице настроек
  скачиваются по ссылкам.

Ограничения макета
------------------
- Скриптов нет: формы не отправляются, кнопки-действия не работают.
- Внешние ссылки (egais.ru, fsrar.ru и т.п.) неактивны.
- Внутренние ссылки (боковое меню, шестерёнка, техподдержка)
  открывают соответствующие HTML-страницы.
- Данные номинальные; реальных ИНН, ФИО, сертификатов и документов нет.

Состав папки
------------
*.html              — 22 статические страницы
static.css          — правки для статики (меню, анимации)
styles.*.css        — стили приложения
MaterialIcons-*     — шрифт иконок
simeizc-webfont-*   — шрифт
assets\             — иконки, картинки, шаблоны (PDF-бланки — заглушки)
xsd\                — 150 XML-схем документов ЕГАИС
favicon.ico         — иконка сайта
